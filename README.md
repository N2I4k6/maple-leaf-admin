# 🍁 Maple Leaf — Admin

## 📖 О проекте

Админ-панель для управления контентом платформы Maple Leaf. Полный CRUD по сериалам, сезонам, сериям, озвучкам и новостям, загрузка медиафайлов, сводная статистика. Доступ только для авторизованных пользователей.

## 🛠 Стек

- React
- TypeScript
- Vite
- React Router
- Ant Design
- axios
- Sass (SCSS-модули)
